# SMOM平台发布工具（STEP分支）

基于 **Tauri 2.0** 的 SMOM 框架发布管理桌面工具，覆盖"编译 → 配置 → 发布 → 备份 → 还原"完整链路，一站式的发布工作台与服务自发现能力，减少开发与运维人员的重复劳动。

## ✨ 功能特性

### 🚀 发布工作台

- 置顶导航首位，一站式完成发布：**欢迎 → 选择项目 → 代码源（Git / TFS）→ 服务器 → 应用配置 → 预览发布**，分步向导式操作
- 右侧实时聚合发布草稿：待发布清单与实时日志，未完成项高亮提示，预检通过后方可发布
- 复用既有发布链路（主页手动发布、生成发布、文件发布），已保存的应用配置自动带出，避免重复填写
- **新手引导**：首次安装自动弹出全屏真实表单向导，Header 提供重播入口；仅首次安装自动弹出一次，不重复打扰

### 🧩 项目发布（STEP）

- 独立页签承载分步式发布流程：**获取程序集 → 备份 → 打包WPF → 上传程序集 → 发布**，发布按服务实例串行执行「停止服务 → 用暂存程序集替换发布目录 → 启动服务」，适合希望逐步确认再发布的场景
- **程序集管理**下拉菜单（悬停展开）：获取程序集、打包WPF、查看服务端 / 本机程序集、**核对程序集**（以本机为准逐文件比对各服务器暂存程序集的修改时间，统计缺失、时间差异与服务器多出三类差异，支持仅看差异与明细展开；时间比对容差 ±2 秒）
- **上传程序集先清空再上传**：上传前把服务器 `<程序集暂存路径>/<模块名>` 整个目录删除并重建为空目录（原条目数写入日志），保证暂存程序集与本地完全一致——本地已删除的旧文件不会被【发布】一起覆盖到服务内；清空发生在本地打包成功之后，打包失败不动服务器
- **上传更快**：非 WpfClient 模块本地压缩成一个 zip 上传、服务端解压（一次压缩多服务器复用）；上传前先探测服务器解压命令（`unzip` / `Expand-Archive`），不支持则自动回退逐文件上传
- **最新产物前置检查**：获取程序集、上传程序集、打包WPF 前自动检查本机程序集目录是否有阈值时间内（默认 10 分钟，可在发布信息卡配置）修改的文件，没有则列出各目录最新修改时间让你确认后再继续，防止拿旧产物发布
- **实时进度**：打包WPF 的下载逐文件计数并显示字节百分比、压缩显示「已压缩 x/N 个文件」；上传/下载分块传输，进度在同一行日志刷新，不刷屏
- **备份与回退**：服务目录整目录备份到服务器「服务备份路径」（按年月日时分文件夹，重名自动区分）；备份管理支持删除与恢复，恢复自动执行「停止服务 → 替换文件 → 启动服务」
- **服务管理面板**：查询 Windows 服务 / Docker 容器运行状态，支持单行与批量的停止、启动、重启，完成后自动刷新
- **立即停止**：点「停止」立即生效——后端重试、等待轮询、SSH 建连阶段秒级中断；后端重试实时上屏日志
- **操作留痕与回查**：备份、恢复备份、上传程序集、发布完成后自动在服务器对应目录追加一行操作日志（备份/恢复在「服务备份路径」、上传/发布在「程序集暂存路径」下，内容为时间 + 操作信息），发布日志按实例记录「发布开始 / 发布成功 / 发布失败（原因）」，配合服务器管理页的【查看日志】【下载日志】随时回查
- **发布顺序可配**：默认 WebApiHost → WebClient → ScheduleServer → WpfClient → SpcMonitor，设置页可上移/下移调整；备份、上传、发布、服务状态查询与「发布信息」卡的应用类型列表统一按该顺序处理
- **启停等待超时可配**：服务启动、停止确认默认各等 20 秒（设置页 5~300 秒可调），异常服务不会再把后续实例长时间堵住
- **项目记忆**：记住上次选择的项目与环境，下次打开自动恢复（项目被删除时回退默认项目）；切走再切回页签保持页面状态、不重新查询
- 页面内置「功能说明」帮助文档，第一次使用照着快速上手即可

### 📦 项目发布（发布平台主页）

- 四大入口：**编译项目**（MSBuild 构建）、**获取程序集**（DLL 复制）、**手动发布**、**定时发布**
- Dev / Uat / Pro / Other 多环境一键切换，项目配置自动带出
- 发布前备份（可配置远端备份路径）、异步上传开关
- 实时日志面板，支持一键清空，发布日志仅保留最新

### 🗂 项目管理

- SLN 解决方案解析，自动获取模块编译输出路径（Release / Debug、新旧版本）
- MSBuild 一键构建（支持强制重新生成）、DLL 批量复制
- 程序集名称（AssemblyName）查询、Manifest 模块版本号自动升级（末位自增）
- 定时发布任务管理：创建 / 取消 / 查看待执行任务
- 应用配置 TFS 变更集起止值修改

### ⚙️ 应用配置

- 按项目管理五大部署模块：**WebApiHost、ScheduleServer（调度）、WebClient、WpfClient、SpcMonitor**
- 每个模块可绑定多台服务器，分别配置服务标识与发布路径（WpfClient 同样支持多服务器发布）
- 获取dll方式：全部 / 当天 / 最近3天 / 日期范围 / DLL名称 / TFS / Git；TFS 与 Git 下可按**日期**、**变更集**、**最近时间**（按天录入，如 3 表示最近 3 天，每次获取时动态计算范围）查询
- 与发布工作台、主页发布、文件发布、备份还原全链路联动

### 📄 文件发布

- 手动选择本地文件 / 目录，直接发布到指定服务器
- 发布前自动备份，支持远程还原

### 🖥 服务器管理

- SSH 服务器纳管：连接配置、所属项目筛选（支持一键清空）
- 远程命令执行、文件上传下载、Windows 服务启停
- SSH MCP 配置上传，供 AI 编码助手（如 ZCode）直连远程服务器操作
- **服务自发现**：SSH 连接按 systemd / Docker / 进程三条链路自动发现已部署服务路径，按名称自动映射到应用配置各模块；确认导入后直接生成服务条目，一键认领纳管服务器，无法识别模块的服务明确标注跳过
- **服务器日志**：STEP 发布流程会在备份/恢复/上传/发布后自动向服务器写入操作日志；操作列【查看日志】【下载日志】按「备份 / 恢复 / 上传 / 发布」选择，弹窗直接展示该日志最新 100 行，或另存到本机；日志文件分别位于服务器的服务备份路径、程序集暂存路径下（Windows 走 PowerShell `Get-Content -Tail`、Docker/Linux 走 `tail`，中文路径与内容不乱码）
- 配套发现前缀管理（设置页），统一约定服务路径扫描规则

### 🔧 TFS 集成

- TFS 服务器与工作区配置管理
- 获取最新代码、签出 / 签入、撤销本地修改
- 变更集历史查询（按日期 / 用户筛选）、变更集详情与文件差异比较
- 查询记录一键生成发布日志

### 🌿 Git 集成

- Git 仓库配置管理
- 提交历史查询、按日期筛选
- 查询记录一键生成发布日志

### 💾 备份记录

- 发布前备份与还原全流程留痕
- 远程还原（含服务启停，遵循重试策略配置）
- 备份导入导出

### 🧊 图标

- 三套图标库一览：SMOM 自绘图标（smom-icon）、FontAwesome（fa）、Element Plus（ele-），按名称模糊搜索并高亮命中片段，分页加载
- 预览设置：尺寸滑块、颜色下拉、复制格式（组件用法 / 类名 / 路由配置），点击图标即复制
- Element Plus 语义色与文字色色板，点击直接应用；附 SvgIcon 属性表与用法示例

### 🛠 设置

- 开机自启动（驻留系统托盘）
- **启动默认菜单**：发布工作台 / 项目发布 / 项目发布(STEP)，保存后下次启动生效
- 重试策略：服务启停重试次数 / 间隔、本地命令重试、文件复制重试、上传重试
- **服务启停等待超时**：启动等待、停止等待分别配置（5~300 秒，默认各 20 秒），超时视为该次启停失败
- **发布顺序**：上移/下移调整 5 个模块的处理次序（默认 WebApiHost → WebClient → ScheduleServer → WpfClient → SpcMonitor），备份 / 上传 / 发布 / 服务状态查询统一生效
- 底部常驻「保存 / 取消保存」按钮栏：配置有改动才可点保存，并提示「当前配置未保存」；取消保存恢复为已保存的配置
- 服务发现前缀管理
- 界面语言切换（简体中文 / English / 繁體中文）、四种布局主题

### ℹ️ 关于与自动更新

- 独立"关于"页面：显示当前版本号，支持手动检查更新
- 启动时自动检查更新，升级弹窗实时拉取 GitHub Release 说明，下载安装一键完成

### 🧊 桌面特性

- 系统托盘驻留、关闭窗口隐藏到托盘、单实例锁
- SQLite 本地存储，数据开机即用，无需外部依赖

## 🚀 快速开始（开发环境）

要求 Node >= 16、npm >= 7，以及 Rust stable 工具链。

```bash
# 克隆项目
git clone https://github.com/nickynull/publish-tools.git

# 进入项目
cd publish-tools

# 安装依赖
npm install

# 开发调试
npm run tauri dev

# 打包桌面应用（输出到 src-tauri/target/release/）
npm run tauri build
```

## 📥 安装与更新

前往 [Releases](https://github.com/nickynull/publish-tools/releases) 下载最新版本安装包，安装即用。应用启动时会自动检查更新，也可在"关于"页面手动检查，升级弹窗会展示对应版本的 Release 说明并支持一键下载安装。
